# Outputs

This directory keeps only the Ligatus result package used by the cleaned repo.

- `ligatus/results/`: CSV/JSON machine outputs.
- `ligatus/results.md`: concise generated results text.
- `ligatus/profile_graphs/`: regenerated by `make ligatus`.
- `ligatus/plots/`: regenerated by `make ligatus`.

Downloaded source RDF is excluded and can be fetched with `make fetch-ligatus`.
